# Для запуска скрипта требуется(без докера)

- Перейти в папку с проектом(используя манипулятор типа "мышь")
- Открыть терминал(правая клавиша манипулятора типа "мышь", в выпадающем меню(на экране ЭВМ), навестись на транспарант "Открыть в терминале", нажать левую кнопку на манипуляторе типа "мышь")
- Используя ввод при помощи клавиатуры, ввести команды
    - Установка библиотек из файла requirements.txt (pip install -r requirements.txt)
    - Создать базу данных в postgres
        1. Подключиться к postgres(psql -h localost -U postgres)
        2. Создать базу данных(CREATE DATABASE test_db;)
        3. Выйти из postgres(\q)
    - Запустить скрипт main.py(python3 main.py из папки со скриптом)
